- core/runlog.py: SQLite data/arena.db with runs, calls (full prompt/response/reasoning/error),
  results, and attempts (code + grade for each attempt).
- core/lineup.py + config/lineups.yaml: a role is a model string or {model, think}.
  Team lineups validate orchestrator/planner/coder/reviewer.
- core/taskboard.py: async TaskBoard Protocol plus a SQLite implementation (atomic claim).
- core/orchestrator.py: run_lineup() -> solve_solo() | solve_team(). MAX_ATTEMPTS=3, MAX_CALLS=20,
  enforced by Session (counts calls + cost, grades and logs attempts). Team loop: planner ->
  coder -> grader; on failure reviewer -> orchestrator (DECISION: RETRY|REPLAN|GIVE_UP,
  unparseable = retry). Every team call is a fresh 1-message conversation (current plan +
  latest attempt only). Replan restarts the coder without the old code. Reviewer and
  orchestrator are skipped after the last attempt and after a reply with no code.
  Worst case 10 calls/problem. Outcome.gave_up marks an orchestrator give-up.
- core/scoreboard.py: every result in every code_bounty run is one trial.
- plugins/code_bounty: grader.py (Docker sandbox, GraderError for infra failures),
  roles.py (solo + team prompts, parse_decision), problems.py (loading + extract_code).
- problems 001-003, each with a reference.py that tests/test_solo.py grades.
- CLI: arena smoke | run --lineup X [--problem 001] | scoreboard
